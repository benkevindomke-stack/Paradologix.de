# Paradologix

Next.js-Webauftritt für Paradologix. Die Projektbasis ist auf Vercel-Deployment vorbereitet.

## Lokaler Start

```bash
pnpm install
pnpm dev
```

## Deployment

Die vollständige Anleitung für GitHub, Vercel und beide Domains steht in [DEPLOYMENT.md](./DEPLOYMENT.md).

Die Domain-Zuordnung ist bereits vorbereitet: `.de` liefert Deutsch aus; Auf `.com` werden dieselben Pfade auf die englische Variante umgeleitet.
